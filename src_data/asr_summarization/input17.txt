Я сейчас готовлю программу для Yandex Camp - летней школы по методам и технологиям NLP, проводимой совместно компанией Яндекс и [АНОНИМИЗИРОВАННЫЙ УНИВЕРСИТЕТ]. Помогите, пожалуйста, заполнить следующие пункты:

1. Какие знания и навыки освоят студенты?
2. Пререквизиты, с чем уже должны быть знакомы студенты, чтобы попасть на данную летнюю школу?
3. Что ждет студентов? (кратко)
4. Какие теоретические знания они получат?
5. Какие практические знания они получат?
6. Есть ли какой-то уникальный опыт, что могут получить только в нашей летней школе?

При заполнении этих пунктов необходимо основываться на следующей учебной программе, которую я разработал для Yandex Camp:

```text
Модуль 1

1. Двухслойные персептроны для языкового моделирования и дистрибутивная семантика для анализа текстов на естественном языке. Метод word2vec, предложенный Томасом Миколовым. Принципы обучения word2vec, преимущества и недостатки этого.

2. Дальнейшее развитие метода word2vec: алгоритмы Paragram, GloVe, FastText.

3. Практическое занятие. Примеры дистрибутивная семантика на языке Python с помощью библиотек pytorch и gensim.

Модуль 2

4. Проблемы обучаемости многослойных персептронов. Свёрточные нейронные сети Яна Лекуна как вариант решения этих проблем. Структура свёрточной нейронной сети и её нейрофизиологическая подоплёка. 

5. Модификация обратного распространения ошибки для обучения свёрточной нейронной сети.

6. Успехи систем компьютерного зрения на основе свёрточных нейронных сетей. Свёрточная нейронная сеть как генератор иерархических признаковых пространств и распознаватель “в одном флаконе”.

7. Практическое занятие. Примеры обучения свёрточных нейронных сетей на языке Python с помощью библиотеки tensorflow.

Модуль 3

8. Перенос обучения и few-shot learning (обучение на малых обучающих выборках).

9. Практическое занятие. Сравнение свёрточных нейронных сетей с переносом обучения и без него и с многослойными персептронами.

10. Одномерные свёрточные нейронные сети и word2vec для задач анализа текстов. Важность учёта локальных особенностей синтаксической структуры текстов при решении задачи классификации.

11. Практическое занятие. Классификация текстов: свёрточные нейронные сети и word2vec против линейных моделей, случайного леса и многослойных персептронов, использующих “мешок слов”.

12. Распознавание именованных сущностей как задача классификации слов в текстах. Применение свёрточных нейронных сетей для классификации слов в текстах.

13. “Дырявые свёртки” и комбинация с условными случайными полями для повышения эффективности учёта “длинного” контекста.

14. Практическое занятие. Примеры на языке Python с помощью библиотеки pytorch/tensorflow на материалах набора данных Collection3 и на наборах данных семейства CoNLL.

Модуль 4

15. Память и обратные связи в нейронных сетях. Простые рекуррентные нейронные сети. Обратное распространение ошибки “сквозь время” (backpropagation through time) для обучения таких сетей.

16. Проблема обучаемости рекуррентных нейронных сетей и способы её решения: LSTM, GRU, SRU, Echo-State Network и другие.

17. Практическое занятие. Сравнение рекуррентных и свёрточных нейронных сетей для задачи распознавания именованных сущностей. Примеры на языке Python с помощью библиотеки pytorch на материалах набора данных MultiCoNER.

18. Прикладные применения рекуррентных нейронных сетей для задач моделирования языка, генерации текстов и машинного перевода.

19. Метод ELMo (Embeddings from Language MOdels) и его преимущества по сравнению с классическими методами семейства Word2Vec.

20. Практическое занятие. Применение ELMo для получения признаковых пространств в задаче распознавания именованных сущностей. Примеры на языке Python с помощью библиотек tensorflow и kagglehub на материалах набора данных MultiCoNER.

Модуль 5

21. Задача машинного перевода и составная структура “последовательность-в-последовательность” на основе двух рекуррентных нейросетей - кодировщика и декодировщика - для решения этой задачи. 

22. Проблема синтаксиса, лексики и фразеологии в задаче машинного перевода. Механизм внимания в нейронных сетях как способ смягчения остроты этой проблемы. Усиление рекуррентных нейронных сетей механизмом внимания.

23. Практическое занятие. Примеры решения задачи машинного перевода на языке Python с помощью библиотеки Pytorch.

Модуль 6

24. Построение нейронных сетей типа “последовательность-в-последовательность” только на основе механизма внимания, без обратных связей. Модель нейросети типа Трансформер (Transformer). Самовнимание (self-attention) и многоголовочное внимание (multihead attention). Другие составляющие Трансформера: позиционные вектора токенов (postional embeddings) и автоматическое выделение “квазиморфем” (byte-pair encoding).

25. Независимое использование компонентов Трансформера: кодировщика для понимания текстов (семейство BERT) и декодировщика для порождения текстов (семейство GPT).

26. Практическое занятие. Примеры на языке Python с помощью библиотек Pytorch и Transformers.

27. Адаптация нейросетей типа BERT для решения задач классификации текстов и распознавания именованных сущностей.

28. Практическое занятие. Построение распознавателя именованных сущностей с помощью библиотек Pytorch и transformers на материалах набора данных MultiCoNER.

Модуль 7

29. Интерпретируемость нейросетевых моделей и “сны Трансформера”. 

30. Многоязычные Трансформеры и перенос обучения между языками. 

31. Практическое занятие. Примеры построения многоязычных моделей на языке Python с помощью библиотек Pytorch и transformers.

Модуль 8

32. Генеративные нейросети типа GPT для задач порождения текстов.

33. Практическое занятие. Применение RuGPT-3 и более современных GPT-подобных моделей (например, семейства Qwen) для генерации высказываний на русском языке.

34. Тематически и стилистически обусловленное порождение текстов. Непосредственное дообучение GPT. Низкоранговые адаптеры (LoRA): альтернативный вариант донастройки больших языковых моделей.

35. Примеры обусловленной генерации русскоязычных высказываний, построенные на языке Python с помощью библиотек pytorch и transformers.

Модуль 9

36. Развитие методов на базе Трансформера для машинного перевода. Нейросеть Pegasus и другие варианты.

37. Методы автореферирования текстов на основе Трансформеров. 

38. Вопросно-ответные системы на основе Трансформеров и внешних неструктурированных баз знаний. Генерация ответов, обусловленная поиском в базе знаний (Retrieval Augmented Generation, или RAG).

39. Практическое занятие. Дообучение Трансформера типа Qwen для автореферирования больших текстов на русском языке.

Модуль 10

40. Ещё раз об обобщающей способности нейронных сетей. Понятие атаки на нейронную сеть.

41. Виды состязательных атак. Атаки “белого ящика” и “чёрного ящика”. Специфика атак на системы анализа и генерации текстов на естественном языке: jailbreak, prompt injection и другие.

42. Атаки на обучающие данные.

Модуль 11

43. Устойчивость нейронных сетей к сдвигу данных.

44. “Глубокие ансамбли” (deep ensembles) и их аппроксимации с помощью байесовских нейронных сетей.

45. Минимизация инвариантного риска и модель среды в задачах NLP.

46. Проблема галлюцинаций в авторегрессионных моделях языка. Галлюцинация как поведение модели в условиях сдвига данных.
```
