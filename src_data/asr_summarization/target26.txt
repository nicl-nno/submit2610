### Саммари созвона:
**Тема:** Разработка голосового помощника для Revit (САПР в строительстве) на базе ИИ.  
**Участники:**  
- Иван, Виталий Митринский, Роман Главацкий ("Институт философии" — заказчик).  
- Олег Гобузов (Институт теплофизики / Центр ИИ — исполнитель).  

**Ключевые обсуждения:**  
1. **Техническая архитектура:**  
   - Клиент — плагин для Revit (записывает аудио → отправляет на сервер).  
   - Сервер — обработка в два этапа:  
     *Speech-to-Text* (распознавание команд) → *Text-to-Command* (конвертация в JSON-инструкции для Revit).  
   - Безопасность: сервер в локальной сети, без выхода в интернет.  

2. **Этапы реализации:**  
   - **Этап 1 (MVP):** Ограниченный набор команд (20 операций), модели ИИ без дообучения.  
   - **Этап 2:** Расширение функционала, дообучение моделей на строительной лексике, сбор датасета.  

3. **Демо-инструкция (Виталий):**  
   - Показан процесс создания объекта в Revit (оси, стены, перекрытия) с выделением 20 команд для автоматизации.  
   - Примеры: копирование элементов, выравнивание, ввод параметров голосом (например, *"1000 умножить на 3 плюс 500"*).  

4. **Проблема для решения:**  
   - Проектировщики тратят до 80% времени на поиск команд в интерфейсе Revit.  
   - Расчет: 1 операция = перемещение курсора на 0.8–1 м → за день "пробег" достигает **сотен метров**.  

5. **Экономический эффект:**  
   - Сокращение времени проектирования на 10–50% → снижение затрат заказчика, рост зарплат сотрудников (сдельная оплата).  

6. **Дальнейшие шаги:**  
   - "Институт философии": доработка ТЗ, согласование списка команд.  
   - Команда Олега: установка Revit, тестирование демо-инструкции.  
   - Следующая встреча: практическая демонстрация работы в Revit.

### Основные итоги созвона:
1. **Техническая часть подтверждена:** Архитектура (клиент-сервер + NLP) признана реализуемой. Для MVP хватит 20 команд.  
2. **MVP будет запущен без дообучения моделей:** На первом этапе используются готовые решения для минимизации рисков.  
3. **Фокус на метриках:**  
   - Точность распознавания команд (цель — 90% для MVP).  
   - Замер времени операций и "пробега" курсора до/внедрения.  
4. **Практическая польза доказана:** Автоматизация рутинных операций (копирование, ввод размеров) высвободит 10–30% времени проектировщиков.  
5. **Действия:**  
   - Фиксация ТЗ с приложением списка команд (до 5 дней).  
   - Установка Revit командой Центра ИИ.
